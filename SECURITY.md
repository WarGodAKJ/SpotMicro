# Security and safety policy

## Reporting

Open a private GitHub security advisory for a vulnerability that could expose credentials, execute untrusted code, or compromise a connected development system. For public hardware bugs that do not expose sensitive information, open an issue and use the hardware-safety template.

## Hardware hazards

Immediately disconnect battery power if a regulator, battery, controller, driver, wire, or servo becomes unexpectedly hot; if smoke or odor appears; if the Teensy repeatedly resets; or if motion becomes uncontrolled.

Do not publish instructions that bypass over-current protection, battery safeguards, grounding requirements, mechanical support, or VIN/VUSB isolation checks.

The repository is an educational research prototype and has no safety certification. Users are responsible for validating electrical and mechanical changes on their own hardware.
